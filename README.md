# Infini-2048

2048 变体游戏 — 达到2048后棋盘自动扩展，3D渲染，四级材质系统。

## 玩法

- 方向键滑动合并数字，**首次合成2048** → 棋盘+1行列（5×5），后续每翻倍继续扩展
- **连击**：一次滑动多组合并获加成（×1.2 / ×1.5 / ×2.0）
- **撤销**：最多回退50步
- 滚轮缩放棋盘，触屏滑动手势操作

## 材质

| 区间 | 档位 | 效果 |
|------|------|------|
| 2-16 | 哑光 | 磨砂质感，经典配色 |
| 32-256 | 金属 | 银/铜/金/铂，高反射 |
| 512-4096 | 水晶 | clearcoat涂层，半透明微发光 |
| 8192+ | 能量 | 强自发光 |

## 调试面板

按 **`** 键打开：随机填充、预设布局、强制扩棋盘、清空存档。

## 运行

```bash
cd games/2048
npm install
npm run dev       # 开发
npm run build     # 生产构建 → dist/
```

## 技术栈

Vue 3 + Vite + TypeScript + Three.js + Pinia + Vue I18n
